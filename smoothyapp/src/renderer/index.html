Multicam

Auto-switch cameras by active speaker on your timeline.

Multicam for Resolve Free

Runs locally

Apply reads the current Resolve timeline, saves the edit in SmoothyEdit Assets → Resolve, and sends it back automatically. Start Smoothy Connector once per Resolve session.

Connection & manual options

Experimental Lua helper. Sends XML when available, with a source-only fallback for synced source clips and isolated mono microphones.

Manual XML handoff
  1. In Resolve, export your synced timeline: File → Export → Timeline → Final Cut Pro 7 XML.
  2. Load the XML here, map each microphone to a camera, then run Multicam.
  3. Import the saved XML in Resolve using File → Import → Timeline.

Start Workspace → Scripts → Smoothy Connector once per Resolve session. Then load timelines and send results here automatically. Start it from the Scripts menu, not the Console.

Start with normal-speed source clips on separate camera tracks and isolated microphone tracks.

Development support & limitations

The helper tries Resolve’s XML export, then reads a source-only snapshot if export is refused. The snapshot requires matching-rate, normal-speed source clips and isolated mono microphones. It copies source timing and channel selection; grades, transforms, effects, fades, automation and mixer processing are not copied. Its exact native compatibility is still under test. Manual XML supports more audio layouts. The result has ordinary editable cuts with the chosen camera on top and alternates underneath. Decompose nested/multicam clips and remove retiming, transitions and animated effects before export. Run Multicam on a synced source assembly before finishing. Your original timeline is never overwritten.
